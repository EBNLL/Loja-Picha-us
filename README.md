# Loja-Picha-us
#Sobre o projeto
A loja oficial da pichau foi banida, e eles nos pediram para fazer uma nova, com cadastro de clientes, estrada para gerentes, e estoque da loja.

#Estrutura de Pastas
/estoque        #Pasta contendo os arquivos da página do estoque
  /index.html   #Arquivo com código fonte da página do estoque
  /script.js    #Arquivo com o script das funcionalidades da página de estoque
  /style.css    #Arquivo com o código referente á aparencia da página de estoque
/clientes

##Como executar a página localmente  #rquer git e visual studio
Clone o repositório
git clone https://github.com/ImDr3ek/Loja-Picha-us.git

abra no visual studio
code .

execute o arquivo login.html

##Funcionalidades
- **Cadastro**: Permite o cadastro de contas como cliente e gerente
- **Login**: Permite acessar contas existentes como cliente ou como gerente

- **Adicionar item**: Permite a adição de novos itens ao estoque da loja.
- **Remover Item**: Permite a remoção de items ja existentes do estoque da loja.
- **Atualizar produto**: Permite atualizar as informações de um produto existente, como nome, marca, valor e estoque.
- **Mostrar estoque**: Permite a visualização do estoque todo, com todas as informações.
